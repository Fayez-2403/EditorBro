## Patterns across the set
- **Who's watching:** the showcase reels with the biggest reach are music-led with short on-screen lines (Imran 1.27M, Keanu 119K). The Claude/AI tool reels get their comments from a **comment-keyword funnel** (1,311 and 2,367 comments).
- **Hooks that work:**
  - an object turning into a world (Keanu, GTA billboard);
  - a pattern break (Imran's style switch);
  - "this was made by typing" (Akshay, Miftahul).
- **No one shows the repo itself** as a place. That gap is ours: the repo is a city you enter by the highway, and every district is something it can build.
