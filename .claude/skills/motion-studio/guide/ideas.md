# 20 reel ideas and use cases (Tech पे Trek, built with the 20-repo stack)

**How to use this list:**
- Pick the idea whose shape fits the topic, or combine two. Say which you picked and why.
- Keep the channel rules: Hinglish, exact facts, Liam voice, 9:16 60 fps.
- Every idea needs its own world. Never reuse the last reel's look.

| # | Idea | Hook / shape | Best for | Tools |

| 1 | **Search wall (the pack's own film, 9:16)** | A search bar types the query, Enter slams, and results pop out on dotted 8ths, each big for a beat before it flies to a wall. Frame 1 = the full wall, so the cover holds the list. | "Top 10/20 tools / repos / prompts" lists (saves) | P cards, B or T walls, N timeline, S/Pb/L score, Pi, F |
| 2 | **Repo round-up in a terminal** | `git clone` types out, and each repo bursts from the terminal as a hologram card with its real stars/licence (fetched, dated) | GitHub repo weeks | P (real repo cards), R, N, To key clicks |
| 3 | **Launch explainer with the real footage** | The company's own demo clips in a built frame (marquee, monitor, phone), with diagrams we draw over them | model / product launches (Genie 4, GPT-6.1 Terra) | R, F (clip prep), O (frame picks), N score |
| 4 | **Data story with count-ups** | One number slams in, then the chart morphs (bars → line → map); each bar lands on a beat | results, hiring data, IPO numbers | R or pdoom, N (eases), Pi (colour checks) |
| 5 | **Case board / incident replay** | A red-string board or a canvas "memory floor" shows what leaked, when, and how it was fixed, from the vendor's post | security incidents (Cloudflare KV, Railway, LiteLLM) | pdoom/R canvas world, P receipts of the real post, N |
| 6 | **Mascot character loop** | A clay-toy mascot (our own, never someone's logo) reacts to every beat; the loop is the joke | channel identity, recurring series openers | B (clay, AgX, DoF), N springs, S/Pb sound, O seam check |
| 7 | **Build A vs build B split** | The same prompt goes to two models; the two builds play side by side with a measured diff | model comparisons (Motion Flex) | R split, F stacks, measure.py colour/strobe on both |
| 8 | **World being simulated** | Terrain erodes, water carves, a city grows, all from a real sim, not a fake one | world models, simulation news, climate data | Nb (sim_erosion), N, T or B to render the height field |
| 9 | **Music-led beat reel** | Every cut on a measured beat; lyric or keyword captions punch on the downbeat | trending audio (IG-music master, no baked song), hype edits | N/S beat grid from the track, R/pdoom, L |
| 10 | **Prompt pack + PDF funnel** | "Comment PACK": the reel shows the pack's pages flipping, and the DM gets the PDF we built | lead magnets, monetising (the @0xCodila angle) | Rl pack_pdf.py, P page renders, R |
| 11 | **How this reel was made (behind the code)** | Contact sheets, the follow-up rounds with their numbers, before/after stills: "Round 3 mein poora idea badal diya" | creator / process content, credibility | Pi sheets, measure.py numbers, R |
| 12 | **UI state walk-through** | SEARCH → RESULT → DETAIL → ACTION → CONFIRMATION; one component morphs across all five states | app features, how-tos ("ye setting on karo") | P (real UI pages, per-state PNGs), G, R |
| 13 | **Leaderboard race** | Bars race on dotted 8ths; the winner hits on the drop; benchmark names, scores and dates exact | model benchmarks, price-per-token comparisons | R/pdoom, N, To or N/S score |
| 14 | **Keyboard / CLI typing film** | A holo keyboard, 4 letters a tap on 16ths, the command runs, the output builds the scene | CLI tools, Claude Code tips, shortcuts | P (terminal states), B or T keyboard, N key-click synth |
| 15 | **Endless-loop news in 15 s** | The last frame = the first; one fact and one visual that wraps; built for rewatches | breaking one-liners, daily AI news | any renderer + `measure.py seam`, LOOP block |
| 16 | **Bollywood dialogue explainer** | A famous filmi line flipped to the topic ("Mere paas ek prompt hai!"), with poster art, stamps and dhishoom SFX | big launches that need drama | R, N score with filmi hits, Pi cover |
| 17 | **3D product turntable with real specs** | The gadget/chip rotates on a lit plinth; each real spec lands as a callout on a beat | hardware launches (phones, GPUs, robots) | B (turntable, AgX, EEVEE), P spec cards, R |
| 18 | **Animated map** | India / world map: regions light up, lines connect data centres or launches, a zoom to the city | data-centre news, rollouts by country | R/pdoom (SVG/canvas map), N, Pi |
| 19 | **App capture reel** | Our own interactive app (ASTRA, AFTERCODE) driven in its `?reel=1` mode, frame by frame, with the song switching per mode | shipping our own apps | P / CDP capture, T/R3F, F, L |
| 20 | **Series template (swap BRAND only)** | One timeline kept and only the BRAND block swapped each week: "AI word of the week", "Repo of the week" | a weekly series at low cost per episode | the whole stack; `guide/brief.md` BRAND block |
